# Portfolio solaire

La version finale du portfolio est `index.html`.

## Structure

- `index.html` : page principale
- `src/solar-portfolio/styles.css` : styles et affichage mobile
- `src/solar-portfolio/data.js` : contenu des rubriques
- `src/solar-portfolio/app.js` : scène 3D et interactions

Le projet utilise Vite. Lance `npm run dev`, puis ouvre la racine du serveur (`/`).
